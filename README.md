## Highlights

- Stable colors for local, remote, virtual, saved, and multi-root workspaces.
- Automatic workspace coloring and reapply by default, with a per-workspace override and safe restore through **Clear Color**.
- Per-surface controls, accessible contrast, and High Contrast support.
- Compact Quick Pick and full settings panel.

## Use

Open a folder or saved workspace and the extension applies its stable derived color automatically. Use **Color My Workspaces: Apply Color from Folder** or the Status Bar item to change it. Applying a color can update workspace settings; review that change before committing it.

Requires VS Code 1.134 or newer on desktop. No telemetry, product network requests, document scanning, or workspace-code execution.
